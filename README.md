# 四格计划

一个个人使用的计划工具：今天、三天、周、月四格联动。前端 React + TypeScript + Vite，后端 Go + Gin，本地数据使用 SQLite。

## 本地启动

需要 Node.js 22.12+、pnpm 和 Go 1.27+。Go 依赖、构建缓存和数据库位于本项目目录内，前端依赖由 pnpm 管理；不改变全局配置。

```sh
pnpm install
pnpm dev
```

打开 http://127.0.0.1:5178。首次进入时创建一个个人账号；之后使用同一昵称和密码登录。没有预置账号或默认密码。后端开发端口为 8788，前端代理 `/api`，无需配置跨域。

`pnpm dev` 会构建并启动 Go 后端、启动 Vite；按 Ctrl+C 同时关闭两者。修改前端会自动更新；修改 Go 文件后需要重新运行 `pnpm dev`。

## 已实现

- 四宫格增删改查、勾选完成、备注和日期调整。
- 计划可在今天、三天、周、月四格之间拖动，目标格子高亮，松手保存；手机可从拖拽握柄移动，编辑弹窗也可修改所属格子。
- 移动保留标题、备注和完成状态；拖到今天使用当前看板日期，三天默认次日（已有后两天日期则保留），周、月使用看板对应的周和月。
- 今天只标记一项优先事项；移到其他格时取消优先标记。周、月的目标还可拆出新的今日行动，并在备注中记录来源。
- 北京时间日历：三天滚动，周一至周日，自然月；支持查看过去和未来日期。
- 普通过期未完成的计划保留在“待重新安排”，手动继续、改期或移除，不自动顺延；持久目标的每日任务留在原日期，不堆积到待重新安排。
- 移除的计划进入回收站，显示原日期、完成状态和删除时间，按最近删除排序，不自动清理；支持恢复和确认后永久删除。电脑侧栏和手机顶栏均可打开。
- 恢复保留原日期、备注及完成状态，不重新设为今日优先；普通过期未完成的计划恢复到“待重新安排”。永久删除实际移除数据库记录，无法通过回收站恢复。导出不包含回收站内容。
- 密码哈希、服务端会话和退出登录；其他窗口更新同一计划时会提示冲突。
- 重新打开页面、切回窗口时刷新；可见页面每 30 秒检查一次最新数据。
- 本地持久保存，服务重启后保留账号、会话和计划；支持导出 JSON 备份。
- 电脑四宫格、手机纵向卡片，键盘可操作的弹窗和控件。
- 界面采用黑白灰配色：黑色主按钮与选中导航、白色卡片、浅灰背景；登录页、弹窗、回收站、进度环和浏览器图标使用同一主题。
- 右上角太阳／月亮按钮切换浅色和深色主题，登录前也可使用。选择保存在当前浏览器，同源窗口同步；首次访问默认跟随系统主题，刷新后沿用保存的选择。深色模式使用黑色背景、深灰卡片和白色主按钮。
- 每格右上角可放大或还原；桌面放大格占据主要区域，其余三格在右侧缩小排列，可直接切换。窄屏和手机将放大格置顶，其余保留为紧凑卡片。放大只调整布局，不改变计划数据。
- 使用 AnimateIcons 和 Motion：导航、计划类型与常用操作图标响应悬停、点击和键盘焦点；放大、切换和还原使用弹簧布局动画，主题按钮切换时渐变旋转。遵循系统的“减少动态效果”设置。
- 今日概览使用 Three.js 黑白星海背景，粒子缓慢漂移与闪烁，随主题调整颜色；只在可见时播放，减少动态效果时静止，WebGL 不可用时显示静态星点。渲染模块按需加载，背景不拦截操作。
- 计划统计：电脑侧栏和看板工具栏提供入口，展示计划总数、完成数、完成率、最长及当前连续完成天数；最近 365 天的热力图支持每天、每周及累计总量、日期提示和方向键查看，手机可在图表内横向滚动。
- 进入计划统计时，热力图从可见区域中心自动播放一次边框波纹；点击日期或周列也会向周围扩散，原有数据颜色保持不变。自动波纹每 10 秒播放一次，可在个人设置关闭；隐藏页面暂停循环，离开图表视口不播放，点击后至少等待 10 秒再自动播放。定时同步不额外重播入场动画，支持键盘 Enter／空格与手机点击，遵循“减少动态效果”设置。
- 统计涵盖所有日期的现有任务实例，持久目标本身不重复计数，回收站和撤销完成的计划不计入。新完成记录使用北京时间实际完成日期，编辑与移动不改变完成日期；历史已完成项以最后修改时间估算并保留估算标记。当天未完成时沿用截至昨天的连续记录，中断一整天后归零。
- 点击头像打开个人设置，资源用量按需显示：当前 Go 进程已分配堆内存，以及 SQLite 数据库文件与 WAL 日志占用；每 30 秒更新，支持手动刷新，读取失败不填入零。当前为本地运行，明确显示 Cloudflare 未接入，不虚构 CF 用量或配额；资源接口需要登录。

## 持久计划与活动历史

- 侧栏「持久计划」创建每日目标，手机顶栏也有入口；可选开始日期，以自然日设置坚持天数或截止日期，包含最后一天。
- 后端按北京时间在读取看板、统计、目标管理或导出时补齐已到来的日期；无需保持浏览器开启，重启后下次访问仍可补齐。尚未到来的日期不创建任务、不提前增加统计总数。
- 每日任务独立完成、编辑、移动和回收；漏做保留为当天未完成任务。完成统计仍按实际完成日期，持久目标卡片按整个日期区间展示目标进度（如完成 1/30 天约为 3%）；计划统计仍按实际生成的任务计数，不提前计入未来任务。
- 修改、暂停、恢复、停止从次日生效，历史内容保留。暂停不延长自然日截止日期，到期不再生成；同一天多次修改按最后一次设置生效。已停止目标保留记录，可新建后续目标。
- 生成游标、按日期的规则版本和每日生成标记保存在 SQLite，事务避免重复生成；即使永久删除单日任务，也不会被补齐机制重新创建。
- 热力图默认最近 365 天，年份选择可以查看历史自然年（闰年 366 天、当年截至今天）；顶部指标仍为全部历史，不随展示年份缩减。移除操作说明、空状态说明和「多／少」图例，保留日期与数量。
- 万象语录的「鼓励」分类在登录后显示，每天缓存一句并保留作者与来源链接；超时、错误或无有效内容则使用内置鼓励文案，当天缓存失败结果以避免重复请求。只发送固定分类，不上传用户名、任务或完成记录。用于本项目的个人试用，来源说明见 https://api.vsaa.cn/detail/19。
- 完成任务显示简短鼓励反馈；主题与自动波纹选项保存在当前浏览器并在同源窗口同步。资源仍是本地 Go 已分配堆与 SQLite 文件占用，Cloudflare 指标尚未接入。
- SQLite 自动升级至版本 3；旧任务内容、版本号与完成日期保留。JSON 导出版本 2 增加持久目标定义，包含未删除的每日任务。

## 手机和其他电脑测试

设备需连接同一 Wi-Fi。先停止现有服务，再运行：

```sh
HOST=0.0.0.0 pnpm dev
```

在手机打开 `http://本机局域网IP:5178`，登录同一账号即可访问同一份后端数据。首次账号设置建议先在本机完成。局域网 HTTP 仅用于开发测试。

可复制 `.env.example` 为 `.env` 设置项目参数，开发和生产启动脚本都会读取它。默认数据库位于 `.data/plans.db`，不要提交 `.data`、`.env` 或导出的个人计划。

## 检查和本地构建

```sh
pnpm check
pnpm test
pnpm build
pnpm start
```

`pnpm start` 用 Gin 同时提供前端和接口，访问 http://127.0.0.1:8788。测试覆盖登录与请求来源保护、日期边界、三天滚动、旧任务重选、优先事项唯一性、窗口修改冲突和重启持久保存。

## 后续 Cloudflare 部署

当前仅开发和运行本地版本，尚未创建云端资源。React 构建结果可交给 Cloudflare 静态托管，Gin 可运行在 Cloudflare Containers。

部署前必须接入持久的云端数据库；不能把当前 SQLite 文件直接放在会被替换的容器文件系统里当作云端存储。还需配置 HTTPS 安全 Cookie、备份和容器入口。Cloudflare Containers 需要 Workers 付费计划，具体部署和存储方案在本地版本确认后落实。

当前为单人空间，不包含开放注册、团队协作、离线编辑或密码找回。多设备同步依赖设备连接同一个后端，不同电脑各自启动本地服务会得到不同数据库。
